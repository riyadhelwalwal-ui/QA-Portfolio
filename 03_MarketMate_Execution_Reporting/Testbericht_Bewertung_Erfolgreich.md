# 📑 Testbericht: Bewertungssystem - Testfall 9 (Erfolgreiche Bewertung)

### 🔗 Testfall-ID: MM-BW-03 (Verifikation einer erfolgreichen Produktbewertung)

#### 🔗 1. Genaue Schritte zur Verifikation (Schritt-für-Schritt):
1. Öffnen Sie die GroceryMate Webshop-Schnittstelle im Browser Chrome.
2. Loggen Sie sich mit einem Account ein, der verifizierter Käufer ist (oder führen Sie vorher einen Checkout durch).
3. Navigieren Sie zur Produktseite des gekauften Artikels.
4. Wählen Sie im Bewertungssystem eine 5-Sterne-Bewertung aus.
5. Geben Sie ein kurzes Textfeedback ein (z. B. "Sehr gutes Produkt!").
6. Klicken Sie auf die Schaltfläche zum Abschicken und beobachten Sie die UI.

#### 🔗 2. Erwartetes Ergebnis (Soll-Verhalten laut Spezifikation):
Das System muss die 5-Sterne-Bewertung und das Textfeedback erfolgreich annehmen, auf der Benutzeroberfläche anzeigen und die Gesamtnote des Produkts live aktualisieren.

#### 🔗 3. Tatsächliches Ergebnis (Ist-Verhalten):
Das System verhält sich korrekt wie spezifiziert. Die Sterne und das Textfeld sind für verifizierte Käufer freigeschaltet. Nach dem Abschicken wird die Bewertung erfolgreich veröffentlicht und der Gesamtdurchschnitt live auf der UI aktualisiert.

#### 🔗 4. Status: PASS 🟢 (Erfolgreiche Produktbewertung erfolgreich verifiziert)
